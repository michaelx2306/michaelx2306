# Trae.ai — SlotSec Lab V3

1. Descomprime el proyecto y abre la carpeta `slotsec-lab-complete`.
2. Ejecuta:

```bash
npm install
npm run validate
npx expo prebuild --platform android
npx expo run:android
```

3. Conecta el teléfono al Wi‑Fi de laboratorio o al AP `SLOTSEC-ALADDIN-01` del ESP32.
4. En la app abre **Escanear → Buscar automáticamente por Wi‑Fi**.

La V3 no usa Bluetooth.
